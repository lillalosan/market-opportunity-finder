Market Opportunity Finder

A private research tool for supporting product research and planning for an Etsy business.

About

Market Opportunity Finder is a private research application developed for product research and planning within an Etsy business.

The application is intended for personal use and operates at limited scale.

Use of the Etsy API

The application uses the official Etsy Open API to retrieve marketplace listing information made available through the API, such as titles, prices, categories and tags.

It does not use scraping or attempt to bypass Etsy's technical controls, and it does not access private data belonging to other sellers.

Status

This is a private personal research project currently under development.

The term "Etsy" is a trademark of Etsy, Inc. This application uses the Etsy API but is not endorsed or certified by Etsy, Inc.
